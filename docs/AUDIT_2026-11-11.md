## What existed

Cells 0–5 load and inspect; cells 6–48 investigate missing-value semantics in train and test using raw re-reads with `keep_default_na=False` to separate the valid "None" veneer category from the "NA" absence marker; cells 49–68 apply seventeen cleaning rules identically to `train_clean` and `test_clean` copies with printed verification counts; cells 69–70 generate the profiling report; cells 71–77 explore the log target (skewness 1.883 raw vs 0.121 log) and the large-house outliers (Ids 524, 1299 investigated, not removed).

## Defects found (severity order)

1. **Reproducibility break.** Cell 65 references `c01_cols`, defined in no surviving cell; execution counts jump 59 → 63. A clean run raises NameError and cell 68's "0 categorical missing" would not reproduce. The C01 behaviour is documented in the cleaning log (pp. 8, 10) and its effect is visible in cell 65's saved output. The code itself is lost in all available copies; the research phase RECONSTRUCTS it and tests the reconstruction. It does not claim recovery.
2. **Execution hygiene.** Non-sequential counts (60–62, 66, 69–71, 78–79 missing), cell 68 has outputs but no execution count, cells 72 and 73 are exact duplicates, cell 71 has duplicate imports and four stale figures, the introduction still describes "four code cells".
3. **Constant flags.** `BasementStatusUnknown`, `GarageYearUnknown`, `MiscFeatureConflict` are always False in train (profile report alerts). `BasementStatusUnknown` is hard-coded to `Id == 2121`.
4. **Test-only categories.** "Unknown" appears only in test for GarageFinish/Qual/Cond, PoolQC, basement fields and the C01 columns; MasVnrType "Unknown" 16 vs 8; MSSubClass 150 occurs only in test (Id 2819).
5. **Test-set anomalies** (lead-verified against test.csv): Id 2593 GarageYrBlt 2207 (built 2006); Id 2550 YrSold 2007 < YearBuilt 2008 and GrLivArea 5095 (Edwards, Partial); Id 1877 YearRemodAdd 2001 < YearBuilt 2002.
6. **Outlier decision pending** for train Ids 524 and 1299 (GrLivArea > 4000, low price, Edwards, Partial). Ids 692 and 1183 are large AND expensive (genuine).
7. **Dictionary vs data spelling**: `Bedroom`/`Kitchen` → `BedroomAbvGr`/`KitchenAbvGr`; MSZoning "C" → "C (all)"; Exterior2nd "BrkComm"/"WdShing" → "Brk Cmn"/"Wd Shng".
8. **Low**: `%pip install fg-data-profiling` inside the notebook (a renamed ydata-profiling 4.20.0 distribution), 49 MB report regenerated each run, `np.log` instead of `log1p` in exploration.

## Preserved (and why)

The missing-value investigation and its rule register are evidence-based, match `data_description.txt`, treat train and test identically, never overwrite recorded values, flag conflicts instead of "fixing" them, and learn nothing from the data (so they are safe to run before any CV split). The integrity assertions (Id order, SalePrice unchanged) and the explicit deferral of learned imputation to training folds are exactly the discipline the research phase keeps.

## Cross-review outcome
